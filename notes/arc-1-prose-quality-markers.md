## Common Patterns Across Multiple Chapters

### Weak Patterns to Avoid:
1. **Overuse of "painted," "hung in the air," "suggested," "seemed"** - appears in almost every chapter
2. **Weather/atmosphere openings** - several chapters open with generic weather/time descriptions
3. **"X looked/appeared/seemed Y"** construction - frequent passive observation
4. **Abstract character analysis** instead of concrete action showing character
5. **Information dumps** disguised as dialogue, especially technical explanations
6. **Repetitive sentence structures** in action sequences: "He did X. The Y happened. Z followed."

### Specific Rewrites Needed:
- **Prologue opening** - Make the meteor strike more specific/visceral
- **Survey opening** - Cut or rewrite generic Amanda arrival
- **Integration opening** - Replace abstract "took on character" with concrete details
- **Multiple chapters** - Replace "painting" metaphor with varied sensory descriptions
- **Action sequences** - Vary sentence structure, fewer passive constructions

## Strongest Sections (Keep as Reference)

The strongest prose tends to be:
1. **Dialogue** (especially Australian idiom)
2. **Technical/practical sequences**
3. **Action scenes**
4. **Character-specific anecdotes**

### Examples of Strong Prose:
- **015.In-shifting-sand.md** - Ginger beer bug anecdote (authentic voice)
- **090.Bushwhackers.md** - Oleksiy introduction and rifle magazine conversation
- **110.Banana.md** - Bull rescue sequence
- **130.Building.md** - Kent learning excavator
- **165.After-Action-Report.md** - Entire document format

## Weakest Prose Locations

The weakest prose tends to be:
1. **Chapter openings** (often generic scene-setting)
2. **Transitions between scenes**
3. **Character internal analysis** (telling vs showing)
4. **Descriptive passages using common AI patterns**

## Revision Priority

1. Fix obvious typos ("The was" → "There was")
2. Strengthen chapter openings with specific, Australian details
3. Replace overused metaphors ("painting everything in red")
4. Vary sentence structure in action sequences
5. Show character through action rather than abstract analysis
6. Integrate technical information into action/dialogue naturally
